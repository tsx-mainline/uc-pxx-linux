# The panel as one Home Assistant device over the ESPHome native API
# (tsx-esphome). python3 and the libraries that aioesphomeapi and the device
# code import (zeroconf, protobuf, cryptography for the API encryption, tzlocal,
# aiohappyeyeballs). The other libraries are pinned wheels that install-lva.sh
# of the package tsx-ha puts into /opt/lva/lib. python3 also runs the setup page
# (tsx-setupd) and the firmware tool.
# voice: the Assist satellite linux-voice-assistant (install-lva.sh of tsx-ha).
# It needs py3-numpy for the wake word, and py3-mpv with mpv-libs to play
# replies on ALSA. The TFLite library for the wake word comes from the
# tensorflow-lite-c package (packages-tsx.txt).

py3-tzlocal
py3-aiohappyeyeballs
